# skimis-mcp-registry

Static MCP Registry for GitHub Copilot (hosted on GitHub Pages).

## Registry Base URL

Use this URL in GitHub Enterprise MCP Registry setting:

`https://ski99042.github.io/skimis-mcp-registry`

> Do **not** append `/v0.1/servers` manually.

## Endpoints

- `GET /v0.1/servers`
- `GET /v0.1/servers/microsoft-learn`
- `GET /v0.1/servers/microsoft-learn/versions/latest`
